# Strategia

1. **Przeczytaj wszystkie zadania** (5 min) – zacznij od tego, które umiesz najlepiej
2. Najpierw **działające** rozwiązanie, potem ładne
3. Uruchamiaj testy po każdym kroku:

```bash
python -m unittest discover -s tests -v
```

4. Nie zmieniaj **nazw plików, funkcji ani parametrów**
5. 10 minut przed końcem: sprawdź, czy wszystko się uruchamia i oddaj
