# Podstawy programowania w języku Python

## Opis kursu
Repozytorium zawiera kompletny program kursu **Podstawy programowania w języku Python**, obejmujący fundamenty języka oraz nowoczesne narzędzia wspierające pracę programisty.  
Celem kursu jest przygotowanie studenta do samodzielnego tworzenia aplikacji w Pythonie oraz efektywnego wykorzystania narzędzi AI w procesie programistycznym.

---

## Zakres materiału

### 1. Wprowadzenie do Pythona
- Wprowadzenie do języka Python  
- Typy danych  
- Instrukcje sterujące i pętle  

### 2. Ekosystem Pythona i funkcje
- Moduły i pakiety  
- Tworzenie funkcji  
- Funkcje lambda i obsługa błędów  

### Projekt: Walidacja rejestracji użytkownika
Praktyczne wykorzystanie funkcji, warunków i wyjątków.

### 3. Iteratory, list comprehensions i generatory
- Iteratory  
- List comprehensions  
- Generatory  

### 4. Zaawansowane typy danych
- Listy, krotki, słowniki, zbiory  
- Typy numeryczne i logiczne  
- Zaawansowane struktury danych  

### 5. Praca z datami i czasem
- Daty i kalendarze  
- Strefy czasowe  
- Daty i czasy w Pandas  

### Projekt: Operacje na datach i czasie
Praktyczne obliczenia i formatowanie czasu.

### 6. Menedżery kontekstu
- Słowo kluczowe `with`  
- Tworzenie własnych menedżerów kontekstu  

### 7. Dekoratory
- Funkcje jako obiekty  
- Domknięcia  
- Tworzenie dekoratorów  

### 8. Manipulacja napisami i wyrażenia regularne
- Operacje na stringach  
- Formatowanie  
- Wyrażenia regularne
